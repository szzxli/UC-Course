# UC 智选 / UC SmartPick

Goal-driven course selection for UC students (freshmen + transfers).

- **Scope**: post-admission — UC → graduation / grad school / employment.
- **MVP campuses**: UCLA, UCB, UCSD, UCI, UCSB.
- **Architecture**: static frontend + JSON data, rules engine (local JS) + AI advisor (BYOK).
